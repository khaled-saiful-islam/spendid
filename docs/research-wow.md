# What makes a money app feel "wow" — research and what Spendid does with it

Research done 2026-10-17. Each finding is turned into something built on the person's own data,
never decoration.

## Findings

| Source | Finding |
|---|---|
| Copilot Money (Apple Design Award Innovation finalist) | Praised for "approachable interface and high-quality animations"; a "spending line" shows budget pacing; data on a dark canvas so the numbers are the hero. |
| Monarch Money | The Sankey cash-flow diagram is the "fan favourite", shareable with amounts hidden. Its forward-looking cash-flow forecast is called a standout. |
| Finch (self-care pet) | The pet mirrors the person's progress, grows and changes look; it "has a life" between visits. Rewards come from doing the habit, not from paying. |
| Duolingo / streak UX (Smashing, 2026) | Streaks work through loss aversion, but need safety nets (freezes, grace) so losing one never feels catastrophic. |
| Cleo | Personality modes (roast / hype) and challenges make money talk fun for younger people. |
| Gamification systematic review (2026, 17 studies) | Progress visualisation and real-time feedback support long-term money habits; cash-style rewards only move short-term behaviour. |
| Monzo Salary Sorter | Splitting pay into pots the moment it arrives is one of the most requested features. |
| Ipsos e-wallet landscape, Malaysia 2026 | ~65% of adults use e-wallets; most spending is food & drink, tolls and parking, retail; most people use one or two wallets (TNG, MAE). |
| Fintech UI trends 2026 | Motion as a system that explains state, haptics paired with animation, data storytelling (charts that explain themselves), bottom sheets. |

## What Spendid builds from it

| Idea | Built on |
|---|---|
| **Month pace** on Home: spent-so-far against an even-pace line, a dashed forecast to month end, and where you'll land | Copilot spending line + Monarch forecast |
| **What if…** slider: spend RM X less a day → how the month ends and how much sooner each goal arrives | Monarch forecast, made playful |
| **Money flow** (Sankey): income → needs / wants / savings → categories, shareable with amounts hidden | Monarch Sankey |
| **Pip grows with you**: energy from logging and check-ins, levels, outfits (incl. Raya, Merdeka, Deepavali, CNY), a daily briefing when tapped, live reactions | Finch |
| **Streak shields**: one earned each week, held by Pip, used automatically on a missed day | Duolingo safety nets |
| **Challenges** tracked automatically from spending (no-spend weekend, coffee cutback, cook-at-home week) with progress rings | Cleo challenges + progress visualisation |
| **Roast my month / Hype me** in Ask Spendid, kind and based only on real numbers | Cleo personality modes |
| **Onboarding as a live sorter**: type your pay, watch it pour into jars, then the coin drops and today's number appears | Monzo Salary Sorter |
| **Share to Spendid** from Touch 'n Go / MAE receipt screenshots, and PDF receipts | Malaysian e-wallet habits |
| Haptics on Android and smooth page transitions | 2026 motion trends |
